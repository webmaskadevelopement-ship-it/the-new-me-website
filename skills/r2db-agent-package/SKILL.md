# R2DB Agent Package v2.0

This package is the revised production-oriented version of the Reference-to-Design-Brief system.

## Start here
1. Read `R2DB_MASTER.json`.
2. Read `22_agent_instructions.md`.
3. Populate `00_project_manifest.json` and `01_reference_registry.json`.
4. Process evidence before making design inferences.
5. Keep observed/measured/inferred/recommended values separate.
6. Generate the remaining artifacts.
7. Finish with `18_implementation_brief.md`.
8. Run `20_visual_qa.md` after implementation.

## Important
The package is deliberately designed to prevent false precision, unsupported brand facts, reference conflicts, and uncontrolled AI design bloat.

The section and component libraries are reference libraries, not mandatory content lists.
