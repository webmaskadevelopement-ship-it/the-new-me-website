# Visual QA

## Purpose
Close the loop between reference analysis and actual implementation.

## Workflow
1. Build implementation from the R2DB brief.
2. Capture screenshots at agreed viewport sizes.
3. Compare implementation with reference intent.
4. Identify deviations.
5. Classify each deviation.
6. Fix highest-impact deviations.
7. Capture again.
8. Repeat until acceptance criteria are met.

## QA Dimensions
- Layout
- Typography
- Color
- Spacing
- Imagery/composition
- Component shape
- Responsive behavior
- Interaction/motion
