# Quality Checklist

## Evidence
- [ ] Every major extraction has a truth level.
- [ ] Every major extraction has confidence.
- [ ] Source region is recorded.
- [ ] Unknown values are explicitly marked unknown.
- [ ] Inferences are not presented as facts.

## Design
- [ ] Design intent is explicit.
- [ ] Reference roles and priorities are explicit.
- [ ] Reference conflicts are resolved and logged.
- [ ] Design tokens are reusable.
- [ ] Components have variants/states where relevant.
- [ ] Section purpose and CTA hierarchy are clear.
- [ ] Editorial simplicity is preferred over unnecessary UI.

## Responsive
- [ ] Behavioral transformations are documented.
- [ ] Mobile/tablet/desktop behavior is explicit where needed.
- [ ] Exact breakpoints are not falsely claimed as reference facts.

## Content
- [ ] No invented testimonials.
- [ ] No fake logos or credentials.
- [ ] No unsupported statistics or scientific/medical claims.
- [ ] Content purpose and length constraints are defined.

## Accessibility & SEO
- [ ] One primary H1 per page.
- [ ] Logical H2/H3 hierarchy.
- [ ] WCAG AA contrast target.
- [ ] Visible keyboard focus.
- [ ] Semantic HTML.
- [ ] Alt text requirements.
- [ ] Reduced motion.
- [ ] SEO intent and metadata requirements.

## Implementation
- [ ] Technical stack is explicit.
- [ ] Asset strategy is explicit.
- [ ] Reusable components are preferred.
- [ ] Visual QA has been performed.
- [ ] Highest-impact visual deviations are fixed.
