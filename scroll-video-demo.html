Scroll Video Ready & Cloned

All dependencies and files required to create scroll videos have been copied and configured in this folder. You can use this exact pattern anywhere in The New Me website.

1. GSAP Dependencies

Self-contained in vendor/gsap/gsap.min.js and vendor/gsap/ScrollTrigger.min.js. No npm installation required.

2. Script Controller

Managed by scroll-video.js. Handles frame caching, resize math, scrubber jumps, and ScrollTrigger pinning.

3. Dedicated Stylesheet

Contained in scroll-video.css. Keeps all video styling isolated from your existing style.css?v=navbar_sticky.

How to Add to index.html

Include the CSS in your <head>:

<link rel="stylesheet" href="scroll-video.css">

Place the section wherever you want the video to pin:

<section id="scroll-video-experience" class="scroll-video-section"> <!-- (See scroll-video-demo.html for inner markup) --> </section>

Include the scripts before the closing </body> tag:

<script src="vendor/gsap/gsap.min.js"></script> <script src="vendor/gsap/ScrollTrigger.min.js"></script> <script src="scroll-video.js"></script>
